Detailed Description

Implements the interactive menu interface for the social network application.

Contains the main console-driven menu that allows users to create, modify, and explore a social network, performing actions such as adding users, connecting friendships, sending messages, and exporting data.

void runMenu ( SocialNetwork &  net)

Runs the interactive console-based menu for user interaction.

Provides numbered options for performing operations on the SocialNetwork such as:

  • Adding/removing users and friendships.
  • Sending messages and creating posts.
  • Viewing network statistics.
  • Exporting to files and DOT graphs.
  • Generating random users.

Includes logging for every user action through the Logger utility.

netReference to the active SocialNetwork instance.
